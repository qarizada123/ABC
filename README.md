# Quran Global

یک وب‌سایت React کاملاً استاتیک و راست‌به‌چپ برای تجربه آنلاین قرآن کریم. این نمونه بدون بک‌اند طراحی شده و شامل صفحه فرود حرفه‌ای، مصحف دیجیتال نمونه، جستجوی نمایشی، بخش صوتی، برنامه‌های حفظ/ختم و قابلیت‌های جهانی چندزبانه است.

## اجرا

```bash
npm run dev
```

سپس آدرس `http://localhost:5173` را باز کنید.

## بررسی استاتیک

```bash
npm run build
```

این دستور فایل‌های اصلی سایت را بررسی می‌کند و نیاز به نصب وابستگی ندارد.
